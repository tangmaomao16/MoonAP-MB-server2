# Gomoku

## Description

Run a browser-local Gomoku game compiled from MoonBit.

## When To Use

Use this skill when the user asks to play or generate a browser board game, especially five-in-a-row or Gomoku.

## Inputs

- `play_mode`: default `single_player`; allowed values: `single_player`, `two_player`.
- `board_size`: default `15`; allowed values: `15`, `19`.

## Privacy

No user file is required. Game state runs in the browser.

## Program

MoonBit sources live in `program/`. The runtime protocol is `interactive-events`.
