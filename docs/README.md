# Docs Index

MoonAP documentation is organized by purpose.

## Structure

- `modes/`
  Development and runtime modes such as `Codex-demo mode` and `Codex-threads-dev mode`.

- `architecture/`
  System summaries and subsystem design notes.

- `plans/`
  Forward-looking implementation plans.

- `notes/`
  Working notes, reflections, and hand-authored development observations.

- `experiments/`
  Experiment-specific artifacts and archived evaluation materials.
